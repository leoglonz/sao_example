# Surrogate Model Example

Minimal self-contained demonstration of the Surrogate-Aided Optimization (SAO) framework, covering:

1. **Pretraining with Sensitivity Constraints (SC)** — LSTM surrogate trained on pre-generated HBV simulations with a Jacobian-matching regularization term.
2. **Online Surrogate Update** — fine-tuning the surrogate on fresh physics model data generated during differentiable model training.
3. **Inference and Evaluation** — evaluation metrics and hydrograph comparison against the reference HBV model.

---

## Requirements

Python ≥ 3.10. Install the framework from the project root:

```bash
pip install -e /path/to/sao
```

Additional dependencies (included in the framework install):

```bash
torch, zarr, numpy, matplotlib, pandas, tqdm, pyyaml
```

## Running the example

Open `example.ipynb` in Jupyter and run all cells top to bottom.

Training with the default settings (10 pretrain epochs, 5 fine-tuning epochs, CPU) completes in approximately **10–20 minutes** on a standard laptop.

To accelerate, either:
- Set `device: cuda` if a GPU is available (automatic detection in the notebook).
- Reduce `epochs` and `n_batches` in `conf/surrogate.yaml`.

---

## Configuration

All settings are controlled via `conf/surrogate.yaml`. Key options:

| Key | Default | Description |
|---|---|---|
| `model.hidden_size` | 64 | LSTM hidden units |
| `data.rho` | 365 | Sequence window length (days) |
| `data.n_batches` | 20 | Minibatches per epoch |
| `pretrain.epochs` | 10 | Pretraining epochs |
| `pretrain.sc_p` | [0, 2] | HBV parameter indices for sensitivity constraints |
| `pretrain.sc_interval` | 1 | Apply SC loss every N epochs |
| `online.ft_epochs` | 5 | Surrogate fine-tuning epochs per online update |

## Data format

The zarr stores in `data/` contain pre-computed HBV simulations over 20 basins.
Each store exposes the following arrays:

| Array | Shape | Description |
|---|---|---|
| `forcings` | `(nt, 20, 3)` | Precipitation, temperature, PET |
| `parameters` | `(nt, 20, 12)` | Sampled HBV parameter sets |
| `target` | `(nt, 20)` | HBV-simulated runoff (mm/day) |
| `jacobians` | `(4, 20, nt, 12)` | ∂runoff/∂params at 4 timestep positions |
| `j_t_idx` | `(4,)` | Timestep positions for the Jacobians |
| `norm_stats/target` | `(2, 20)` | Per-basin mean and std (log-transformed) |
| `norm_stats/jacobians` | `(2, 12)` | Per-parameter mean and std |

Full-scale datasets (531 basins) are generated by running `python -m sao mode=build_buffer`.
